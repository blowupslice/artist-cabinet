# Личный кабинет артиста

Сайт, где каждый артист по своей почте и паролю видит:

- **профиль** и подписанные договоры (скачать);
- **финансовый отчёт по кварталам**: доход по каждому треку и каждой площадке, доля, динамика к прошлому кварталу;
- **детализированный отчёт** (исходный файл от дистрибьютора) и **сводку в Excel**;
- **акт для подписания** и статус акта (ожидает / подписан).

Вы управляете всем через админку `/admin/`: создаёте артистов, задаёте пароли, загружаете договоры, отчёты и акты.

Каждый артист видит только свои данные. Файлы не лежат в открытом доступе: любое скачивание проходит проверку, что файл принадлежит этому артисту.

## Как этим пользоваться (для вас как администратора)

1. Зайдите на `https://ваш-домен/admin/` под своим аккаунтом.
2. **Артисты → Добавить.** Укажите email (это логин), пароль и имя. Сохраните и сами отправьте артисту логин и пароль.
3. На той же странице артиста:
   - в блоке **«Договоры»** загрузите PDF подписанных договоров;
   - в блоке **«Квартальные отчёты»** нажмите «Добавить», выберите год и квартал, загрузите файл дистрибьютора (.xlsx или .csv) и акт.
4. После сохранения сайт сразу разбирает файл, и внизу блока появляется «Итог по файлу» (сумма, прослушивания, число строк). Если сайт не узнал колонки в файле, он покажет ошибку со списком заголовков, которые нашёл.
5. Когда артист вернёт подписанный акт, загрузите скан в поле «Подписанный акт»: статус сам сменится на «Подписан». Можно и массово: «Квартальные отчёты» → выбрать → действие «Отметить акты как подписанные».
6. Чтобы проверить, что видит артист, нажмите в списке артистов **«Кабинет глазами артиста ↗»**.

Галочка «Показывать артисту» позволяет загрузить отчёт заранее и открыть его позже.
Галочка «Доступ открыт» у артиста закрывает ему вход, не удаляя данные.

### Какой файл отчёта подходит

Excel (.xlsx) или CSV, в котором есть колонки с **треком**, **площадкой** и **суммой**. Колонки с прослушиваниями, ISRC и страной необязательны. Строки заголовка над таблицей, итоговые строки и разбивка по месяцам не мешают: одинаковые трек + площадка суммируются.

Колонки узнаются по названию («Название трека», «Track title», «Площадка», «Store», «Сумма, руб», «Net revenue» и т. д.). Если ваш дистрибьютор пишет иначе, добавьте его вариант в словарь `COLUMN_ALIASES` в файле `cabinet/importer.py`.

Старый формат .xls не поддерживается, его нужно пересохранить в .xlsx.

## Запуск на сервере одной командой (рекомендуется)

1. Загрузите все файлы проекта в публичный репозиторий на GitHub.
2. Арендуйте сервер с Ubuntu 22.04 или 24.04, подключитесь к нему и выполните:

```bash
curl -fsSL https://raw.githubusercontent.com/ЛОГИН/РЕПОЗИТОРИЙ/main/install.sh | REPO=ЛОГИН/РЕПОЗИТОРИЙ bash
```

Скрипт установит всё сам, задаст несколько вопросов (домен, название, ваш email и пароль администратора), включит HTTPS и ежедневные резервные копии.
Если домена пока нет, сайт будет работать по адресу вида `1-2-3-4.sslip.io`, где 1.2.3.4 — IP сервера.
Чтобы обновить сайт после изменений на GitHub, запустите ту же команду ещё раз.
Чтобы сменить домен: `RECONFIGURE=1` перед `bash` в той же команде.

## Запуск на сервере через Docker (альтернатива)

Понадобится:
- VPS с Ubuntu 22.04/24.04 (хватит 1 CPU / 1 ГБ RAM, например у Timeweb, Selectel или REG.RU);
- домен или поддомен, например `cabinet.mylabel.ru`, у которого **A-запись** указывает на IP сервера.

```bash
# 1. Установить Docker
curl -fsSL https://get.docker.com | sh

# 2. Загрузить проект на сервер (например, scp или git) и перейти в папку
cd artist-cabinet

# 3. Настройки
cp .env.example .env
nano .env          # впишите домен, SECRET_KEY, название кабинета, контакт

# 4. Запуск (HTTPS-сертификат выпустится автоматически)
docker compose up -d --build

# 5. Создать свой аккаунт администратора
docker compose exec app python manage.py createsuperuser
```

После этого откройте `https://ваш-домен/admin/`.

**Обновление** после изменений в коде: `docker compose up -d --build`.

### Резервные копии

Все данные (база и загруженные файлы) лежат в папке `data/` рядом с проектом. Достаточно регулярно её копировать, например раз в сутки по cron:

```bash
tar czf /root/backups/cabinet-$(date +%F).tar.gz -C /путь/к/artist-cabinet data
```

## Локальный запуск (посмотреть на своём компьютере)

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python manage.py migrate
python manage.py seed_demo      # демо-артист с отчётами
python manage.py runserver
```

- Кабинет: http://127.0.0.1:8000, вход `demo@example.com` / `demo-pass-2026`
- Админка: http://127.0.0.1:8000/admin/, вход `admin@example.com` / `demo-pass-2026`

Тесты: `python manage.py test cabinet`

## Устройство проекта

| Файл | Что внутри |
|---|---|
| `cabinet/models.py` | Пользователь (логин = email), Артист, Договор, Квартальный отчёт, Строки отчёта |
| `cabinet/importer.py` | Разбор Excel/CSV дистрибьютора |
| `cabinet/admin.py` | Админка |
| `cabinet/views.py` | Страницы кабинета, скачивание файлов, выгрузка сводки |
| `cabinet/templates/cabinet/` | HTML-шаблоны |
| `cabinet/static/cabinet/style.css` | Оформление (светлая и тёмная тема, мобильная версия) |

Защита: после 10 неудачных попыток вход по этому email блокируется на 15 минут. Пароли хранятся в зашифрованном виде (хэш), cookie передаются только по HTTPS.
